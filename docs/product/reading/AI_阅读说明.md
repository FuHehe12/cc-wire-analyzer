# 阅读说明

本书介绍 CC Wire Analyzer 的功能、操作方法、功能要求与后续设计。当前功能说明对应 v0.4.26；其他版本的菜单和行为可能有所不同。

## 从哪里开始

初次使用从第 1 节的“使用方法”开始，完成接入和第一次录制。之后按“录制 → 找到 → 读懂 → 关系 → 分析 → 产出”查看相应章节。

- **使用方法**：具体入口、操作步骤、预期结果和常见问题。
- **当前功能**：软件已经怎样工作，以及适用范围和限制。
- **功能要求**：功能应遵循的行为规则；请结合“提供情况”阅读，不能据此认定全部已经实现。
- **后续设计**：尚未提供或尚待确定的能力。涉及调查容器、片段标记、判断修订、行动跟进与观测 Agent 整合时，不能当作现有操作手册。

顶部可以搜索关键词或条目编号，也可只查看使用方法或当前功能与截图。相关内容按钮可以跳到关联说明。

各工作流还包含操作详解、报文阅读、轨迹方法和设计原理。需要按问题寻找新整合的内容时，打开 [内容整合与阅读路径](AI_内容整合与阅读路径.md)。

## 图与分析怎么理解

本书包含 11 张本次采集的操作截图和 3 张历史截图。操作截图来自本地 v0.4.26 对应源码的真实浏览器界面，使用隔离的合成示例数据；源码运行时版本显示为 dev。红色编号圈出操作入口或阅读重点，点击图片可放大查看。

示例记录不是真实用户任务，也不是模型分析效果证明。历史截图仅辅助说明布局，与当前版本的差异见各图图注。

模型分析属于解释，关系匹配可能属于推断。需要判断原因时，应回到对应请求、响应和工具结果；没有记录不能自动理解为没有发生。

## 在线阅读与分享

本地构建后打开 dist/manual/index.html 即可阅读，无需启动软件。单文件可以复制到其他目录，章节链接用于本地定位。页面中的 Markdown、OPML 与 JSON 导出用于整理需求数据，不是阅读说明书的前置步骤。

本书没有内嵌项目内部历史讨论。代码摘录供开发者理解局部实现，不代表运行测试报告。公开分享录制、快照或新截图前，请自行检查其中的请求内容和配置数据。
