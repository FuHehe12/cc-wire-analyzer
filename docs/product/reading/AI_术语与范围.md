# 术语与范围

| 术语 | 含义 |
|---|---|
| 录制 / capture | 软件保存的一次上游请求及其响应、时间与相关元数据。保存内容受采集和解析范围限制。 |
| 来源 / source | 本机录制或导入数据的来源。跨来源查询需要明确选择。 |
| 会话 | 用于归并相关请求的范围，不必然等于一个完整的现实任务。 |
| 时序 / DAG | 请求及其关系的图形展示；某些边来自匹配推断。 |
| 快照 / snapshot | 保存的请求或提示词材料，用于后续阅读、比较和分析。 |
| 八视图 | 轨迹分析的多种表达方式；语义归纳与机械计算需要区分。 |
| coverage | 查询实际覆盖的数据范围。没有匹配结果不等于所有数据中都不存在。 |
| 调查记录 | 后续设计中组织疑问、材料、判断和行动的容器，当前不等于已有快照。 |
| 观测 Agent | 后续设计方向：通过对话、查询与图形帮助理解执行过程，具体触发方式与权限仍待确定。 |

功能介绍面向人类使用者和通过本地 HTTP 接口工作的 Agent。接口入口与查询步骤见第 9 节使用方法；模型配置见第 8 节。本书没有承诺自动找出唯一根因，也不把推断结果视为已经验证的事实。
