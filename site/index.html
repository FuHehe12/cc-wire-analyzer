Local records.
Clear data boundaries.

Local storage and network forwarding are different. Check the endpoint and scope before using model analysis.

Recording
Claude Code requests pass through the local proxy to the configured upstream model. The app saves records locally.
Reading
Reading saved requests and deterministic statistics needs no analysis model. Records support local compaction and archiving.
Model analysis
Translation, AI explanations and semantic analysis send the relevant content to the model endpoint you configure.
Sharing & updates
Record bodies may contain messages, files and sensitive data. Review them before sharing. Update checks and downloads also use the network.
