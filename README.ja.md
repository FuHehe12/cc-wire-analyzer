# CC Wire Analyzer — Claude Code のプロンプト、思考過程、サブエージェントの動作を可視化

Claude Code は「何をしたか」は教えてくれますが、知りたいのは「なぜ」であることも少なくありません。どの非表示の呼び出しが失敗したのか、自動モードは何を待っているのか、サブエージェントにはどんなプロンプトが渡ったのか、モデルが実際に受け取った system prompt は何か。

CC Wire Analyzer は、Claude Code と上流の間で交わされるリクエストとレスポンスをローカルに記録し、舞台裏の動きをキャプチャ一覧、リクエスト詳細、タイムライン、比較可能なスナップショットとして整理します。自分で確認するだけでなく、agent に検索や分析を任せることもできます。

## こんな問題を調べられます

- **セーフティ分類器や非表示の呼び出しでエラーが出る**：失敗したリクエストを見つけ、上流から返された実際のエラーと、関連するプロンプト、モデル設定、ツール呼び出しを確認できます。
- **自動モードが急に遅くなる**：総所要時間と初回応答時間を比較し、thinking、再試行、タイトル生成、セーフティ審査、Token カウントなど、どこで待っているのかを切り分けられます。
- **モデルが実際に受け取った内容を確認したい**：system prompt、Messages、ツール定義、thinking の全文を展開できます。英語や複数言語が混在する内容は、原文を残したまま翻訳できます。
- **サブエージェントの動作が分かりにくい**：タイムラインで派生関係をたどり、誰が誰を起動したのか、Task / Agent がどのプロンプトを使ったのか、各サブエージェントにどのコンテキストが渡ったのかを確認できます。
- **agent に詳しく調べさせたい**：記録は機械可読な JSONL で保存され、ローカル HTTP API からも参照できます。1 件ずつ手作業で開かなくても、agent が検索、比較、エラーの集約を行えます。

## 3 分で始める

1. [Releases](../../releases) から Windows 版または macOS 版をダウンロードして起動します。
2. 「キャプチャ」タブで「プロキシ開始」をクリックし、新しい Claude Code セッションを開きます。
3. Claude Code を普段どおり使い、調べたい現象を再現します。
4. CCWA に戻り、まずキャプチャ一覧で疑わしいリクエストを絞り込み、詳細またはタイムラインを開きます。agent にローカル分析 API を直接読ませることもできます。

調査が終わったら、「プロキシ停止」をクリックするかアプリを終了します。

## キャプチャを 1 件分析する

### 1. キャプチャ一覧で異常なリクエストを絞り込む

キャプチャ一覧の各行は、上流へのリクエストを 1 件ずつ表しています。まず、次の 4 種類の情報を確認します。

| 情報 | 分かること |
|---|---|
| 種類 | メイン、タイトル生成、セーフティ審査、サブエージェント、コンテキスト圧縮などが、それぞれ何回呼び出されたか |
| 総所要時間 / 初回応答時間 | 最初のレスポンスを待っているのか、生成処理そのものが遅いのか |
| Token / キャッシュ | どのターンでコンテキストが急増したか、キャッシュが繰り返し読み込まれているか |
| ステータス / 要約 | 上流エラー、審査結果、レスポンスの要約。赤い失敗行が最も直接的な手掛かりになることが多い |

たとえば、自動モードが遅いなら所要時間が突出した行を探します。セーフティ分類器に問題があるなら、「安全」または失敗した行から追います。セッション全体を手探りで読む必要はありません。

### 2. 詳細を開き、モデルが実際に受け取った内容を確認する

リクエストをクリックし、調べたい内容に応じて該当セクションを開きます。

- **System**：system prompt 全文、身分、コンテキスト reminder、キャッシュ属性。
- **Messages**：ユーザーメッセージ、会話履歴、ツール結果、Claude Code が注入したコンテキスト。
- **Content Blocks**：thinking、text、tool_use、エラー、停止理由。
- **Tools**：そのリクエストでモデルに提示されたツールと、各ツール schema の詳細。

各テキストブロックは、コピー、整形、翻訳、設定済み AI による解説が可能です。翻訳と解説は原文を置き換えず、横に表示されるため、その場で内容を照合できます。

### 3. タイムラインと Analyse でリクエスト間の関係を確認する

- 「タイムライン」タブでは、メイン、サブエージェント、補助呼び出しが別々のレーンに表示されます。派生エッジから誰が誰を起動したかをたどり、時間軸から待機、再試行、連続エラーを見つけられます。
- 「Analyse」タブでは、リクエスト全体またはプロンプトの一部をスナップショットとして保存し、ターンごとのプロンプト、コンテキスト、thinking、不可視文字の差分を比較できます。

### 4. agent に分析させる

多数のリクエストにまたがる問題なら、1 件ずつ手作業で開く必要はありません。CCWA の GUI と agent は同じローカル API を利用します。サービスの起動後、まず agent に次のように指示します。

> このマシンで CC Wire Analyzer が動いています。`http://127.0.0.1:<port>/api/ai-guide` を読み、説明に従って今回の記録にある失敗、遅いリクエスト、サブエージェントの動作を調べてください。

ポートは `~/.cc-wire-analyzer/port.txt` に記録されています。agent は要約とエラー集約を確認してから、ID を指定して個別の詳細を取得できます。手順全体は [AI 使用ガイド](docs/reference/AI_USAGE.md) を参照してください。

## 主な機能

- **透過的な記録**：SSE を転送しながら記録します。Anthropic 公式への直接接続と、サードパーティの互換エンドポイントに対応しています。
- **詳細情報**：リクエスト、レスポンス、system prompt、Messages、ツール、thinking、Token 使用量、上流エラーを保持します。
- **呼び出し関係**：タイムライン DAG で、メイン、サブエージェント、補助呼び出しをつなぎます。
- **コンテンツ分析**：整形、翻訳、AI 解説、スナップショット、精密な差分比較、思考チェーンの階層表示に対応しています。
- **機械可読**：ローカル JSONL、HTTP API、CLI を使って、検索、集計、自動診断を行えます。
- **クロスプラットフォームのデスクトップアプリ**：Windows `.exe` と macOS `.app` を提供しています。Python のインストールは不要です。

## インストールと実行

### リリース版をダウンロードする

[Releases](../../releases) から、最新の Windows 実行ファイルまたは macOS の圧縮ファイルをダウンロードします。

- **Windows**：`.exe` をダブルクリックします。WebView2 が見つからないというメッセージが表示された場合は、[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) をインストールしてください。
- **macOS**：展開したアプリを `/Applications` にドラッグします。アプリはまだ署名・公証されていないため、初回は右クリックして「開く」を選ぶか、「システム設定 → プライバシーとセキュリティ」で「このまま開く」を選択してください。

### ソースから実行する

```bash
git clone https://github.com/FuHehe12/cc-wire-analyzer.git
cd cc-wire-analyzer
uv sync                 # Windows
uv sync --extra mac     # macOS
uv run python src/desktop.py
```
